# Search and restore

Press **⌥⌘D** (Windows: **Ctrl+Alt+D**) from anywhere to open the search panel. It searches everything in the archive by title, site and address, most relevant first, grouped by day and by the window things came from. With nothing typed, it shows the most recent.

## Keys

| Key | Does |
| --- | --- |
| Return | Restores the selected tab into its original window |
| ⌥ Return (Windows: Alt+Enter) | Restores it into a new window |
| ⌘ Return (Windows: Ctrl+Enter) | Restores the whole group, in order ([Decay Pro](/docs/pro)) |
| ⌘P (Windows: Ctrl+P) | **Always keep** this site |
| ⌘I (Windows: Ctrl+I) | Shows its details in the Library |
| Esc | Closes the panel |

## Where tabs come back

A tab reopens in the browser **and profile** it came from. If that profile isn't open (or its Decay extension isn't connected), Decay says which one, and offers to open it in another connected profile instead.

## The Library

The Library (menu → Open Library) lists everything archived, recent sweeps with Undo, the week's shadow review, and insights about your tabs. A restored tab gets 48 hours of grace before it can be archived again.

## Undo

After each sweep, Undo puts back what it archived. The last 20 sweeps can be undone from the Library's Sweeps page or the menu (Undo last sweep).
