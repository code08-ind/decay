# App windows

Besides browser tabs, Decay watches your apps' windows (turn it on or off in Settings → General → Window access).

- A window you haven't used in a while is **hidden**: minimised to the Dock (Windows: the taskbar), at a quiet moment, a few at a time. Click it to bring it back: it's fresh again. Undo brings back a whole hide sweep.
- Windows are never closed, with one exception in [Decay Pro](/docs/pro): **Finder and Explorer folder windows** that have stayed hidden past the archive threshold are closed and kept in the archive. Restoring one reopens the folder. Explorer windows with several tabs are never closed.
- Full-screen windows, windows that can't be minimised, and the window you're using are left alone.

**macOS:** window access needs Accessibility (System Settings → Privacy & Security → Accessibility). **Windows:** no permission needed.
