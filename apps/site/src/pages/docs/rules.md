# Rules

Settings → Protection holds your rules. Each applies to a **site** (and its subdomains), a **web address pattern**, an **app**, or a **window title**.

- **Always keep:** Decay never archives or hides it. A few are there from the start (sign-in pages and video calls). ⌘P in the search panel adds one for a result's site.
- **Never record:** Decay doesn't store it at all, and deletes what it already stored for it (you're asked first, with a count). Settings → Privacy & data lists them.
- **Custom timing:** its own pace, for example "let youtube.com go twice as soon". Without [Decay Pro](/docs/pro), the first three apply.

**Test** a rule as you write it: Decay shows which open tabs and archived items it matches before you save it.
